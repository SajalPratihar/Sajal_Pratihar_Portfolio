# Sajal Pratihar — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. No build tools or package installation are required.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

For a local development server, you can use the VS Code **Live Server** extension.

## Customize before publishing
- Replace `assets/profile-placeholder.svg` with your own photo. Rename your photo to `profile.jpg`, then update the image path in `index.html` to `assets/profile.jpg`.
- Review the About, experience, education, skills, and project descriptions to ensure every detail is current and shareable.
- Add your LinkedIn, GitHub, and live project URLs if you want them displayed.
- Update the page title and meta description in `index.html` if needed.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/profile-placeholder.svg` — replaceable profile image placeholder

## Publish
You can deploy this static website using GitHub Pages, Netlify, or any web server that can host HTML/CSS/JS files.
